# roystondwork-dev/scoop-bucket

[Scoop](https://scoop.sh) bucket for [portcheck](https://github.com/roystondwork-dev/portcheck): see what's using your ports, find free ones, free them up, and check remote hosts.

```powershell
scoop bucket add portcheck https://github.com/roystondwork-dev/scoop-bucket
scoop install portcheck
```

`portcheck.json` is generated by GoReleaser on every portcheck release. Please do not edit it by hand, and open issues in the [portcheck repository](https://github.com/roystondwork-dev/portcheck/issues).
